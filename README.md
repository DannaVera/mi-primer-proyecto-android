# Mi primer proyecto Android

Proyecto de ejemplo que:

1. Soporta cuatro idiomas: español (por defecto), inglés, francés y alemán.
2. Usa como fondo una imagen en formato nine-patch (`fondo.9.png`) redimensionable; el marciano Android no se deforma.
3. Se adapta a distintos tamaños y orientaciones de pantalla (teléfono vertical/horizontal y tablet).

Para compilar, abre la carpeta en Android Studio y ejecuta la app en un emulador.
